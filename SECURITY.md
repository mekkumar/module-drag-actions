# Security Policy

## Supported Versions

Security fixes are currently provided for the latest maintained release.

| Version | Supported |
|---------|-----------|
| 1.x     | Yes       |
| < 1.0   | No        |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub Issues.

Instead, contact the repository maintainer privately with:

- A description of the vulnerability.
- Steps to reproduce.
- Potential impact.
- Any relevant proof of concept.

Please allow reasonable time for the issue to be investigated and addressed
before publicly disclosing the vulnerability.
