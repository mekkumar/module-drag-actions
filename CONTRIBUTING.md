# Contributing

Contributions, bug reports, feature requests, and improvements are welcome.

## Reporting Bugs

Before opening an issue:

1. Check existing issues.
2. Confirm that the issue is reproducible.
3. Include Magento version.
4. Include PHP version.
5. Include browser information when the issue is frontend-related.
6. Include relevant console or server errors.
7. Provide clear reproduction steps.

## Feature Requests

When requesting a feature, please explain:

- What problem the feature solves.
- Expected behaviour.
- Current behaviour.
- Whether the feature affects desktop, mobile, or both.

## Pull Requests

Before submitting a pull request:

1. Keep changes focused.
2. Follow Magento coding conventions.
3. Avoid unnecessary changes to unrelated files.
4. Test the affected functionality.
5. Update documentation when required.
6. Update `CHANGELOG.md` when appropriate.

## Code Style

Please follow Magento 2 and PSR coding standards.

## Security

Do not publicly disclose security vulnerabilities through GitHub Issues.

For security-related concerns, contact the repository maintainer privately.
